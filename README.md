# Jane Street Puzzles

A collection of solvers and interactive tools for Jane Street’s monthly puzzles, created as practice in AI-assisted software development. These projects explore how to guide an AI coding assistant through implementation, testing, and refinement, while using mathematical reasoning and experimentation to develop better solving strategies.

Each puzzle has its own folder containing code, instructions, and supporting files. Where included, personal reflections discuss the development process, the approaches that worked or failed, and lessons learned about working with AI. The aim is both to solve interesting puzzles and to become more effective at directing and evaluating AI-assisted development.
